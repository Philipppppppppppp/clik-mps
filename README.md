CLIK-MPS
Complex-Time Lindbladian Krylov Subspace Matrix Product States
This repository will provide a tensor-network toolkit for computing steady states and low-lying spectral properties of open quantum many-body systems using the CLIK-MPS framework introduced in:
P. Westhoff, M. Moroder, U. Schollwöck, and S. Paeckel, A Tensor Network Framework for Lindbladian Spectra and Steady States arXiv:2509.07709 (https://doi.org/10.1103/7kd1-kxxz)
CLIK-MPS is a tensor-network approach for targeting the low-lying eigenvalues and eigenmodes of Lindbladians. The method combines matrix-product-state representations of vectorized density operators with complex-time evolution, traceless initial states and a Krylov-subspace construction.

Status: Work in progress
The user interface and public API of the toolkit are not finalized yet.  A first usable version of the toolkit will be released once the interface has been completed and stabilized.
Until then, this repository should be considered a development repository. The structure below describes the intended organization of the toolkit and may change during development.

Overview
The main goal of CLIK-MPS is to provide an efficient framework for spectral calculations of large open quantum many-body systems.
The central workflow is

Lindbladian
    │
    ▼
Warm-up / state preparation of physical/traceless states
    │
    ▼
Real and Complex-time evolution
    │
    ▼
Krylov subspace construction
    │
    ▼
Effective Lindbladian
    │
    ▼
Non-Hermitian diagonalization to extract
    │
    ├── Steady state
    ├── Right eigenmodes
    ├── Left eigenmodes
    └── Low-lying eigenvalues

The framework is based on representing vectorized density operators as MPS and using time evolution to construct a Krylov subspace generated by the Lindbladian. Complex-time evolution is used to control the relative damping of different spectral modes.
